# Blog preview card

This is a responsive solution to the [Blog preview card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS).

## Overview

### The challenge

Users should be able to:

- View the blog preview card on mobile and desktop screen sizes.
- See a clear visual state when focusing or hovering over the article title.
- Read the content with a logical semantic HTML structure.

## What I learned

This project provided practice with:

- Structuring a small component with semantic HTML.
- Using CSS custom properties for a consistent color palette.
- Centering content with CSS Grid.
- Creating the card's offset shadow with `box-shadow`.
- Adding keyboard-visible focus styles with `:focus-visible`.
- Building a layout that works from 320px-wide screens through larger desktop screens.

## Running locally

No build tools or dependencies are required. Open `index.html` in a browser, or serve the project directory with any local static web server.

For example, with the VS Code Live Server extension:

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Select **Go Live**.
